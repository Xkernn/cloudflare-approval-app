BEERLAO VIRTUAL COMPANY 3D — COMPANY HUB PROTOTYPE V1

Entry: /virtual-office/hub.html

Included:
- Central Tower landmark and Central Plaza
- Five clickable gateway destinations: Head Office, Warehouses, Retail Network, Logistics, Province Network
- Free camera (OrbitControls): drag to orbit, scroll/pinch to zoom, right drag/two-finger pan
- Company Overview panel with intentionally blank KPI values (no fabricated live data)
- Dynamic atmosphere based on Asia/Vientiane local time; manual night override
- Responsive desktop/mobile UI
- Link from existing Virtual Company 3D sidebar to this preview

Important:
- This is a visual prototype and gateway interaction preview. It does not yet load the legacy office/warehouse/logistics scenes when a gateway is selected.
- KPI values are placeholders (—), not live company data.
- Existing index.html route and existing 3D modules are retained.
- Three.js r128 and matching OrbitControls are loaded from jsDelivr CDN.

To preview locally, serve the public directory over HTTP and open /virtual-office/hub.html. Do not open as file:// because browser module/CDN policies may vary.
