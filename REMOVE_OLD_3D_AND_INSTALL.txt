BEERLAO VIRTUAL COMPANY 3D — MENU INTEGRATION PATCH V3

SCOPE
- The existing "Virtual Company 3D" menu item and Admin-only visibility are preserved.
- Its click destination changes from /virtual-office/ to /company-world/.
- New Company Hub is served from public/company-world/.
- The old 3D runtime is removed from public/virtual-office/.
- No backend, API, database, schema, authentication, role, or other business workflows are changed.

APPLY
1. Extract this ZIP into the project root, preserving folder paths.
2. Review public/index.html diff. Only the Virtual Company 3D destination/comment should differ.
3. Run `apply-patch.ps1` (Windows PowerShell) or `sh apply-patch.sh` (Linux/macOS) from the project root. It deletes only `public/virtual-office/`.
   Alternatively, delete that directory manually.
4. Deploy the normal application static assets.
